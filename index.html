Quem sou eu

Sou engenheira civil que descobriu nos dados uma forma mais poderosa de fazer o que sempre fez bem: entender problemas e tomar decisões com base em evidências.

A transição para Ciência de Dados foi natural, com a lógica estrutural, o raciocínio analítico, a atenção a detalhes que a engenharia exige... tudo isso chegou junto na bagagem. Hoje aplico esse repertório trabalhando com Python, SQL e visualização de dados para transformar conjuntos de dados complexos em respostas claras.

Estou construindo meu portfólio de forma independente, projeto a projeto, entendendo cada etapa do ciclo de vida dos dados, da ingestão ao modelo, do dado bruto ao insight.
